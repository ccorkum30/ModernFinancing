# ModernTools

Modern Exteriors field tools — a branded hub of sales tools for the team.

- **Home** (`index.html`) — the tools menu.
- **Financing Calculator** (`financing.html`) — enter a total estimate to see monthly payment options.
- **Templates** (`templates.html`) — fill-in Call Pilot note (Call Pilot / Install Notes / Sales Notes), copy-ready.

Static site, no dependencies. Served via GitHub Pages from the `main` branch at
https://ccorkum30.github.io/ModernTools/
